# Privacy Policy for Sitemap XML Validator

**Effective Date:** 2026

Sitemap XML Validator does not collect, store, or share any personal user data.

## What the Extension Does

The extension processes sitemap XML content from:

* The currently active browser tab
* A URL manually entered by the user

All processing happens locally within the user's browser.

## Data Usage

* No personal data is collected
* No data is sent to external servers
* No analytics or tracking tools are used

## Permissions

* **activeTab** → Detect sitemap XML on current page
* **storage** → Save last entered URL (optional)
* **host permissions** → Fetch sitemap XML from provided URLs

## Data Sharing

The extension does **not** sell or transfer user data to third parties.
